# Alina Sales — приложение торговой команды Alina Group

Веб-приложение для торговых агентов (iPhone, Safari → «На экран Домой»):
выбрал маршрут → «Маршрут в 2ГИС» (от текущего местоположения) → на точке заполнил анкету → «✓ Выполнено» → «📋 Дать задание».
Результаты сразу пишутся в Google Таблицу. Точка, которую взял агент, у остальных уходит в «Заняты».

- Приложение: https://courierrr.github.io/alina-2gis-baza/
- Таблица: https://docs.google.com/spreadsheets/d/1oRPVrFF2sFYXrY0BhRwPIdrvxdial3cAhP-Ej8xwY08/edit
- Вход: имя и свой 4-значный PIN (задаётся при первом входе), дальше — PIN или Face ID. Руководитель — сотрудник, который один раз ввёл код руководителя (задаётся в таблице, см. ниже).
- Маршруты 1–5 — 571 точка из Excel, маршрут 6 «Точки продаж ССС и ЛКП» — 41 точка из Google Таблицы «Точки продаж на карте КЗ».
- Логотип и цвета — с сайта Alina Group (alina.kz).

## Возможности
- **Вход по PIN / Face ID.** При первом входе сотрудник вводит имя и придумывает PIN (4 цифры). Приложение просит PIN или Face ID при запуске и после 15 минут в фоне. 5 неверных PIN подряд — вход на 15 минут закрыт. PIN хранится в таблице только хэшем. Сервер принимает запросы только с подписанным токеном входа.
- **Личный кабинет** (кнопка с именем в шапке): цель дня со шкалой до 100%, начало/конец рабочего дня с GPS, статистика за день / неделю / месяц (точки, новые точки, повторные визиты, задания), «Мои дела» — даты следующего шага из анкет, смена PIN, Face ID.
- **Карта маршрута** (кнопка в списке точек): точки цветом по статусу, «Где я». Карта — OpenStreetMap.
- **Визиты.** Анкета точки: контакты, работаем / не работаем, ассортимент, конкуренты, наши бренды, интерес, фото витрины. Сворачиваемые разделы по шаблону оценки ТТ: точка, помещение и склад; оборудование (полки и торцы FAWORI, Alina Paint, AlinEX, V-tech; КО); брендинг; фейсы и паллеты; объёмы продаж и доли брендов; билборды и мастер-классы. Колонка «Баллы ТТ» считается по шкалам шаблона. Выполненную точку можно посетить снова — «🔁 Новый визит», у точки видна история визитов.
- **GPS-отметка.** При отправке анкеты сохраняется местоположение агента и расстояние до точки (если у точки есть координаты). Визиты дальше 300 м видны руководителю.
- **Задания.** На карточке точки — «📋 Дать задание»: отметить одно или несколько заданий, к каждому комментарий, общий срок:
  - Отработать с командой ОТЭК
  - Отработать по бренду Alina Paint и NORMA
  - Отработать по бренду AlinEX и НАШИ
  - Отработать по бренду V-tech, Alina Paint Alkyd
  - Отработать по бренду FAWORI
  - Отработать по брендингу в торговой точке

  Задания видны всей команде в разделе «📋 Задания». Агент нажимает «Беру себе» — задание закрепляется за ним; закрывает «✓ Выполнено» с описанием результата и фото (до 3). Просроченные подсвечиваются красным.
- **Руководитель.** В кабинете «Я руководитель» → код (или при первом входе). На главной появляется «📊 Статистика команды»: блок «Сегодня» (кто начал день, шкала цели каждого), карта команды (последний визит и начало дня), «Сотрудники» (сброс PIN, блокировка, роль), кабинет любого агента; визиты, новые точки, визиты далеко от точки и без GPS, задания (выдано / взято / выполнено / просрочено, среднее время выполнения), таблица по агентам и лента действий (кто, когда взял и выполнил). В «Заданиях» — вкладка «Все» с фильтрами и отменой заданий.
- **АКБ.** На главной — итог по всем маршрутам: сколько точек загружено, сколько выполнено, в штуках и процентах.
- **Новый адрес.** Круглая кнопка посередине снизу → «Я на месте»: координаты и адрес берутся из геолокации телефона (адрес можно поправить). Если в 100 м уже есть точка из базы, приложение её покажет, чтобы не завести дубль. Точка попадает в отдельный маршрут «Новые точки» в конец листа «Точки», в колонке «Добавил» — кто добавил.
- **Точки рядом.** Пока приложение открыто и человек не за рулём, приложение проверяет точки в радиусе 500 м (свободные и свои в работе) и показывает уведомление «Рядом есть точка — навестите». Каждая точка — один раз в день. Веб-приложение не получает геолокацию в фоне, поэтому при закрытом приложении уведомлений нет.
- **Карта команды в реальном времени.** Пока приложение открыто, телефон отправляет местоположение (раз в 45 с или при движении), карта руководителя обновляется каждые 20 с. Приложение закрыто — на карте последнее известное место и время. Последняя позиция хранится в свойствах скрипта, а не в листах таблицы.
- **Нерабочие точки.** На карточке точки: «Точка не работает / закрылась» → причина и комментарий. Точка уходит в отдельный список (вкладка маршрута и общий экран), в расчёт АКБ не входит, строка в листе «Точки» красная. Вернуть может отметивший или руководитель.
- **Отчёт за день у руководителя.** Страница «Команда → Отчёт за день» (адрес `#/report/ГГГГ-ММ-ДД`): главные цифры, что требует внимания, точки с высоким интересом, сотрудники с раскрытием точек по порядку, вся анкета по нажатию. Открывается только после входа по PIN сотрудника с ролью руководителя. Кнопка «Скачать Excel» собирает простой файл: итог дня и точки.
- **Письмо.** Каждый день в 16:00 по Алматы на почту уходит короткий итог и кнопка «Открыть отчёт», без вложения (адрес — в меню таблицы «Адрес для ежедневного отчёта…»). В день без активности письма нет. Кнопка в отчёте отправляет письмо вручную за любую дату. Триггер ставит функция `reportSetup` (запустить один раз в редакторе).
- **Без связи** анкета сохраняется на телефоне и отправляется автоматически, когда связь появится.

## Что где лежит
| Файл | Назначение |
|---|---|
| `index.html`, `app.js`, `styles.css` | приложение |
| `config.js` | ссылка на Google Apps Script (`API_URL`) |
| `icons/` | логотип Alina Group и иконки приложения |
| `data/routes.json` | 571 точка из Excel (маршруты 1–5; маршрут 6 хранится только в Google Таблице) |
| `apps-script/Code.gs` | бэкенд для Google Таблицы |
| `tools/xlsx-to-json.ps1` | пересобрать `routes.json` из нового Excel |
| `tools/serve.ps1` | локальная проверка: http://localhost:8080/ (демо-режим: http://localhost:8080/?mock) |

Пока `API_URL` пустой (или в адресе `?mock`), приложение работает в **демо-режиме** (данные только на этом устройстве, код руководителя любой).

## 1. GitHub Pages
Репозиторий → **Settings → Pages** → Source: *Deploy from a branch*, Branch: `main`, папка `/ (root)`.
Изменения появляются на сайте через 1–2 минуты после `git push`.

В репозитории только названия и адреса из 2ГИС. Собранные контакты, задания и журнал хранятся в Google Таблице, не на GitHub.
Код руководителя в репозитории **не хранится**.

## 2. Google Таблица
Первая установка:
1. **Расширения → Apps Script**, удалите всё в `Код.gs`, вставьте содержимое `apps-script/Code.gs`, сохраните (💾).
2. Обновите вкладку с таблицей — появится меню **Alina Sales**.
3. **Alina Sales → 1. Загрузить точки** → вставьте `https://courierrr.github.io/alina-2gis-baza/data/routes.json`.
   Google попросит разрешения: *Проверить разрешения → аккаунт → Дополнительно → Перейти в проект → Разрешить*.
4. **Alina Sales → 2. Геокодировать адреса** — проставит координаты (3–5 минут). Если в конце написано «Осталось», запустите ещё раз.
5. **Alina Sales → Код руководителя…** — введите код входа для руководства.
6. В Apps Script: **Начать развертывание → Новое развертывание** → тип **Веб-приложение**,
   «Выполнять от имени»: **Я**, «Кто имеет доступ»: **Все** → Развернуть → скопируйте URL (заканчивается на `/exec`) в `config.js`.

**Обновление `Code.gs`** (после изменений в репозитории):
1. Вставьте новый `Code.gs` целиком вместо старого → сохранить (💾).
2. Обновите вкладку таблицы; если код руководителя ещё не задан — **Alina Sales → Код руководителя…**.
3. **Развертывание → Управление развертываниями → ✏️ → Версия: Новая версия → Развернуть** (URL не меняется).

## 3. iPhone
Откройте ссылку GitHub Pages в **Safari** → кнопка «Поделиться» → **На экран «Домой»**. Введите имя.
Для кнопки «Маршрут в 2ГИС» лучше, чтобы было установлено приложение 2ГИС; без него откроется сайт 2ГИС.
Разрешите Safari доступ к геолокации — иначе визиты будут «без GPS».

## Как пользоваться таблицей
- **Точки** — все точки: статус (свободна / в работе / выполнена), агент, время, число визитов. Чтобы вернуть точку в свободные — сотрите статус и агента, либо меню «Освободить точки „в работе“ старше 24 ч».
- **Маршрут 1…6** — анкеты визитов (по строке на визит): контакты, ассортимент, конкуренты, интерес, итог, фото, № визита, GPS агента, расстояние до точки; правее — поля шаблона оценки ТТ (оборудование, площади, продажи и т. д.), числа записаны числами.
- **Задания** — все задания: точка, задание, комментарий, срок, кто выдал, статус (новое / в работе / выполнено / отменено), исполнитель, время, результат, фото.
- **Журнал** — все действия агентов по времени (из него лента руководителя).
- **Сотрудники** — имя, роль, статус, последний вход (PIN только хэшем). Забыл PIN — руководитель жмёт «Сбросить PIN» в приложении.
- **День** — цель дня и время начала/конца рабочего дня каждого агента.
- Фото — в Google Drive, папка «Alina 2GIS фото / Маршрут N» и «… / Задания».
- Выгрузка в Excel: **Файл → Скачать → Microsoft Excel (.xlsx)**.

## Заявки на баннеры
Приложение заявок встроено экраном: копия лежит в `zayavki/`, открывается карточкой на «Сегодня» и кнопкой «Заявка на баннер» на точке (название и адрес подставляются сами). Правки заявок делаются здесь, в `zayavki/index.html`.

- Сервер заявок свой (`zayavki/config.js`): номера, голосовой помощник, Google Диск и письмо на почту отдела работают отдельно от таблицы Alina Sales.
- Отправленная заявка копируется в лист «Заявки на баннеры» этой таблицы; руководитель видит список в **Команда → Заявки на баннеры**. Заявки из старого значка туда не попадают.
- Черновики хранятся на телефоне. Старое приложение `COURIERRR/zayavki` продолжает работать отдельно.

## Маршруты по районам
Шесть маршрутов разбиты по районам города отдельным слоем: колонки «Зона» и «№ в зоне» в конце листа «Точки». Старый номер маршрута, id, анкеты, фото, задания и статусы не меняются.

- Новая точка, добавленная с места, сама попадает в ближайшую зону. Точка без координат остаётся в «Новых точках», пока ей не назначат зону.
- Анкеты остаются в прежних листах «Маршрут N», поэтому номер листа может отличаться от номера маршрута в приложении.
- «Навести порядок в зонах» в меню таблицы: точка переходит к маршруту, которого среди соседей больше. Назначенные вручную точки не двигаются.
- Управление: в приложении **Команда → Маршруты по районам** или в меню таблицы **Alina Sales**: рассчитать черновик, назначить маршруты точкам (`R1-089=3, R2-052=5`), включить новые, вернуть старые.

## Новая база
```
powershell -ExecutionPolicy Bypass -File tools\xlsx-to-json.ps1 -Xlsx "C:\путь\Маршруты.xlsx"
```
Запушьте обновлённый `data/routes.json` и снова нажмите «1. Загрузить точки» — добавятся только новые id, статусы старых сохранятся.

## Точки из Google Таблицы (как маршрут 6)
Таблицы формата «Точки продаж на карте КЗ» (№, Город, Название в 1С, Канал, Название, Адрес, Телефон, WhatsApp, Почта, Ссылка 2ГИС)
загружаются прямо в Google Таблицу функцией `importSalesSheet(id таблицы, имя листа, № маршрута, название, координаты)` в Apps Script —
так названия клиентов из 1С и их телефоны не попадают в публичный репозиторий. Точки без координат потом геокодируются меню «2. Геокодировать адреса».
