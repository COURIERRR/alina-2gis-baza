# Alina Group — Отработка базы 2ГИС

Веб-приложение для агентов (iPhone, Safari → «На экран Домой»):
выбрал маршрут → «Маршрут в 2ГИС» (от текущего местоположения) → на точке заполнил анкету → «✓ Выполнено».
Результаты сразу пишутся в Google Таблицу — отдельный лист на каждый маршрут. Точка, которую взял агент, у остальных пропадает из списка.

## Что где лежит
| Файл | Назначение |
|---|---|
| `index.html`, `app.js`, `styles.css` | приложение |
| `config.js` | ссылка на Google Apps Script (`API_URL`) |
| `data/routes.json` | 571 точка из Excel (5 маршрутов) |
| `apps-script/Code.gs` | бэкенд для Google Таблицы |
| `tools/xlsx-to-json.ps1` | пересобрать `routes.json` из нового Excel |
| `tools/serve.ps1` | локальная проверка: http://localhost:8080/ |

Пока `API_URL` пустой, приложение работает в **демо-режиме** (данные только на этом устройстве).

## 1. GitHub Pages
1. На github.com создайте **пустой публичный** репозиторий `alina-2gis-baza` (без README).
2. Отправьте код:
   ```
   git remote add origin https://github.com/ЛОГИН/alina-2gis-baza.git
   git push -u origin main
   ```
3. Репозиторий → **Settings → Pages** → Source: *Deploy from a branch*, Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт доступен: `https://ЛОГИН.github.io/alina-2gis-baza/`.

В репозитории только названия и адреса из 2ГИС. Собранные контакты хранятся в Google Таблице, не на GitHub.

## 2. Google Таблица
1. Создайте новую Google Таблицу, например «Alina 2ГИС — Отработка базы».
2. **Расширения → Apps Script**, удалите всё в `Код.gs`, вставьте содержимое `apps-script/Code.gs`, сохраните (💾).
3. Обновите вкладку с таблицей — появится меню **Alina 2ГИС**.
4. **Alina 2ГИС → 1. Загрузить точки** → вставьте `https://ЛОГИН.github.io/alina-2gis-baza/data/routes.json`.
   Google попросит разрешения: *Проверить разрешения → аккаунт → Дополнительно → Перейти в проект → Разрешить*.
   Появятся листы «Точки» и «Маршрут 1…5».
5. **Alina 2ГИС → 2. Геокодировать адреса** — проставит координаты (3–5 минут). Если в конце написано «Осталось», запустите ещё раз.
6. **Alina 2ГИС → 3. Задать код доступа** — придумайте код, его будут вводить агенты.
7. В Apps Script: **Начать развертывание → Новое развертывание** → тип **Веб-приложение**,
   «Выполнять от имени»: **Я**, «Кто имеет доступ»: **Все** → Развернуть → скопируйте URL (заканчивается на `/exec`).
8. Вставьте URL в `config.js` (`API_URL: 'https://script.google.com/macros/s/…/exec'`), закоммитьте и запушьте.

Если позже меняете `Code.gs`: **Развертывание → Управление развертываниями → ✏️ → Версия: Новая версия → Развернуть** (URL не меняется).

## 3. iPhone
Откройте ссылку GitHub Pages в **Safari** → кнопка «Поделиться» → **На экран «Домой»**. Введите имя и код доступа.
Для кнопки «Маршрут в 2ГИС» лучше, чтобы было установлено приложение 2ГИС; без него откроется сайт 2ГИС.

## Как пользоваться таблицей
- **Точки** — все 571 точка: статус (свободна / в работе / выполнена), агент, время. Чтобы вернуть точку в свободные — сотрите статус и агента, либо меню «Освободить точки „в работе“ старше 24 ч».
- **Маршрут 1…5** — заполненные анкеты (контакты, ассортимент, конкуренты, интерес, итог, ссылки на фото).
- Фото — в Google Drive, папка «Alina 2GIS фото / Маршрут N».
- Выгрузка в Excel: **Файл → Скачать → Microsoft Excel (.xlsx)**.

## Новая база
```
powershell -ExecutionPolicy Bypass -File tools\xlsx-to-json.ps1 -Xlsx "C:\путь\Маршруты.xlsx"
```
Запушьте обновлённый `data/routes.json` и снова нажмите «1. Загрузить точки» — добавятся только новые id, статусы старых сохранятся.
